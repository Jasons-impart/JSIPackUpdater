# Minecraft Modpack Updater

```sh
npm install --global @jsi-team/minecraft-modpack-updater
minecraft-modpack-updater gui
```

Provides the native CLI, TUI and GUI for Linux x64, Windows x64, macOS x64 and macOS arm64. Node.js 18 or newer is required for the npm launcher. The portable Release builds do not require Node.js.

bkmpw is detected separately and is not bundled. If missing, choose an instance-local download or npm global installation of `@bro-know-my/packwiz`.

See [tool setup and upgrades](https://github.com/Jasons-impart/JSIPackUpdater/blob/main/docs/tools.md).
