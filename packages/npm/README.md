# Minecraft Modpack Updater

```sh
npm install --global @jsi-team/minecraft-modpack-updater
minecraft-modpack-updater gui
```

Provides the native CLI, TUI and GUI for Linux (glibc), Windows and macOS on x64 and ARM64. npm selects the matching native platform package automatically. Node.js 18 or newer is required for the npm launcher. The portable Release builds do not require Node.js.

bkmpw is detected separately and is not bundled. If missing, choose an instance-local download or npm global installation of `@bro-know-my/packwiz`.

See [usage, tool setup and upgrades](https://github.com/Jasons-impart/JSIPackUpdater#readme).
